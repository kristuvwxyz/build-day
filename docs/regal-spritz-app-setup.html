    2 · Team app in Chrome, no Claude account

    One-time · about 15 min · free

    The app code is already on your main branch and ready. You only make two free accounts: Supabase (the database and email sign-in) and Vercel (the website). Staff then open the site in Chrome and sign in with a code sent to the email listed for them in Admin → Directory.

    0 of 6 done · Tick each step as you go. Your ticks are saved on this device.

    1. Make the database (Supabase)

      • Sign up → New project. Name regal-spritz, region Singapore. Save the database password in your password manager.
      • Type your sign-in email below, tap Copy database script, then in Supabase open SQL Editor → New query, paste, Run. It should say “Success”.
      Open Supabase

    2. Turn on sign-in codes (Supabase)

      • Authentication → Sign In / Providers → Email: make sure it's on.
      • Authentication → Email Templates → Magic Link: replace the message with the text below, then Save.
      Your Regal Spritz sign-in code is {{ .Token }}

      Supabase only sends a few emails an hour for free. Before inviting the whole team, connect a free Resend account under Authentication → Emails → SMTP Settings.

    3. Put it online (Vercel)

      • Sign up with GitHub → import build-day.
      • Root Directory → Edit → pick projects/business-os-app. Framework: Other.
      • Open Environment Variables and add these three. The two Supabase values are in Supabase → Project Settings → API.
      SUPABASE_URLProject URLSUPABASE_ANON_KEYanon public keySHOPIFY_SHOPtjs1uz-4a.myshopify.com
      • Tap Deploy. When it's done, copy your site address (like regal-spritz.vercel.app).
      Open Vercel

    4. Link the address back (Supabase)

      • Authentication → URL Configuration → paste your Vercel address as the Site URL → Save.

    5. Move your data

      • In the claude.ai dashboard: My account → Access & security → Developer options → Download full backup. Keep the file private.
      • Open your new site, sign in with your email and the code you get.
      • My account → Access & security → Import backup → pick the file → wait for “Imported … records”.

      From then on, the team uses the new app. The claude.ai page keeps its old copy and stops matching.

    6. Connect Shopify orders (can be done later)

      • In dev.shopify.com, create an app named Regal Spritz OS, tick the access scopes, release and install it.
      • Add its Client ID and Client secret in Vercel → Settings → Environment Variables as SHOPIFY_CLIENT_ID and SHOPIFY_CLIENT_SECRET, then Redeploy.

    Install it and share with the team

    Scan to install. Send this to the team. Each person opens it once, signs in with the email in the Directory, then installs it:

    • iPhone: Safari → Share → Add to Home Screen
    • Android: Chrome → ⬇ Install app
    • Windows PC (Chrome): click the install icon at the right end of the address bar, or the app's ⬇ Install app button → Install. Then right-click it in the taskbar → Pin to taskbar
    • MacBook (Chrome): same install icon or ⬇ Install app → Install. Then right-click its Dock icon → Options → Keep in Dock
